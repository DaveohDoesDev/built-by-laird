# Built by Laird

Marketing site for **Built by Laird, LLC**, my solo studio building websites for local small businesses.

**Live:** https://daveohdoesdev.github.io/built-by-laird/

## What's here

| Path | Contents |
|---|---|
| `index.html` | The current site design |
| `prototypes/` | Design explorations (tiers 1–4 and variants) |
| `images/` | Images used by the site |
| `CLAUDE.md` | Design directions to avoid, for Claude |

## Updating

Push to `main`, and GitHub Pages republishes the site within a minute or two. To preview locally, run `python3 -m http.server 8000` and open http://localhost:8000.
