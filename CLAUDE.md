# Built by Laird

Marketing site for my LLC, Built by Laird (builtbylaird.com).

## Design directions I've rejected
Don't drift back to these when iterating on the design. I want the site to read as a clean studio, not a brand-themed novelty.

- **No construction or carpentry metaphor.** No hammers, saws, blueprints, "measure twice, cut once", "frame / wire / finish / hand over" process labels, sawdust, lumber textures, or studs and rivets as visual motifs. "Built by Laird" is a neutral wordmark, not an invitation to a metaphor.
- **Not the cream / navy / saturated-orange palette** as first executed (cream `#FAF6F0`, navy `#0F1B2D`, orange `#D9622D`). I like orange in general, so keep it somewhere, but the palette is open for redesign.
- **No visible blueprint or dot grid backgrounds** as decoration on hero or section backgrounds.

Get distinction from typography, color, motion, and layout instead.
